# Python 3.13. Fully pinned -- resolved and verified on 3.13.14 / Windows.
#
# Why 3.13 and not something older or newer:
#   - 3.11/3.12 are security-only; 3.11 reaches EOL Oct 2027. No reason to start
#     a new project on a runtime that old.
#   - 3.14 has no prebuilt tree-sitter wheel (0.26.0 ships cp310-cp313 only), so
#     it would mean compiling a C extension on Windows -- our biggest install risk.
#   - 3.13 has wheels for everything and security support until Oct 2029.
#
# To change a pin: edit here, reinstall, re-run `pytest` and the spikes, and
# commit the result. Do not let this file drift from the venv -- reproducibility
# is a stated requirement of this project, and an unpinned run is an unciteable
# number.

# --- parsing -------------------------------------------------------------
# Grammars ship as prebuilt wheels, so there is no C toolchain requirement.
# This exact core/grammar pairing is VERIFIED: spikes/spike_treesitter.py parses
# Java correctly at grammar ABI 14. Grammar wheels encode an ABI version and a
# newer core can reject an older grammar, so if you bump either one, re-run that
# spike before trusting anything downstream.
tree-sitter==0.26.0
#
# One grammar wheel per supported language. All seven are prebuilt for Windows
# (no C toolchain) and are VERIFIED against core 0.26.0 -- note the mixed ABI:
# the core accepts both 14 and 15, which is exactly the compatibility question
# the warning above is about. Adding a language means adding a wheel here and a
# `LanguageSpec` in src/parse/languages.py; nothing else changes.
#
#   grammar          ABI   notes
tree-sitter-java==0.23.5      # 14
tree-sitter-c-sharp==0.23.5   # 15   return type is `.returns`, not `.type`
tree-sitter-python==0.25.0    # 15   docstring lives INSIDE the body
tree-sitter-cpp==0.23.4       # 14   also claims .h -- see LanguageSpec.suffixes
tree-sitter-c==0.24.2         # 15   name nested under `declarator`
tree-sitter-go==0.25.0        # 15   return type is `.result`
tree-sitter-rust==0.24.2      # 15   `impl` blocks supply the enclosing name
# Fallback if tree-sitter ever breaks on another machine. Pure Python, Java only,
# cannot fail to build. Not currently needed -- kept because swapping to it means
# rewriting only src/parse/parser.py, which is cheap insurance.
javalang==0.13.0
